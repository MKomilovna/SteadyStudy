# 📚 SteadyStudy

SteadyStudy is a modern web application designed to help students prepare for the GKS (Global Korea Scholarship).

## ✨ Features

- 📖 IELTS Task Planner
- 🇰🇷 TOPIK Study Planner
- 🎓 GKS Preparation Tracker
- 🎯 Daily Goals
- ✅ Task Manager
- 📊 Progress Bar
- 📈 Statistics
- 🔥 Daily Streak
- 📅 Study Calendar
- 📚 Vocabulary Notebook
- ⏰ Pomodoro Timer
- 🌙 Dark Mode
- 💾 Local Storage Saving

## 🛠 Built With

- HTML5
- CSS3
- JavaScript
